# How to translate content elements in TYPO3

<!-- #TYPO3v14 #Beginner #ContentElements #Frontend #Backend #Localization @dhubert974 -->

In TYPO3, content elements must be translated individually to provide a fully localized experience for your site visitors. This guide shows you how to translate content elements, use the language menu, and verify the frontend behavior.

Translating content elements enables editors to manage multilingual content efficiently. Configuring a language menu helps users navigate between language versions seamlessly.

## Learning objective

In this step-by-step guide you will learn how to translate individual content elements.

## Prerequisites

### Tools and technology

* TYPO3 v14 installation
* Administrator access to the TYPO3 backend
* A site configured with at least one additional language

### Knowledge and skills

* Basic understanding of TYPO3 backend modules
* Familiarity with page translation

## Translate content elements

1. Open the page in the backend.
2. Locate a content element in the default language.
3. Click Translate on the element.
4. Edit the content for the translated version.
5. Save the translation.

Expected outcome:

* Visitors can view translated content in the frontend.
* TYPO3 links translated content elements to the original language automatically.

## Verify the frontend translation

Confirm that both pages and content elements display correctly in the new language.

1. Open the website frontend.
2. Use the language menu to switch to the translated language.
3. Confirm the following:
   * The URL contains the configured language path
   * Translated pages are accessible
   * Content elements appear in the selected language

## Summary

Congratulations! You have successfully translated individual content elements, used a frontend language menu, and verified multilingual functionality in TYPO3 v14.

## Next steps

Now that you have translated content elements and enabled a language menu, you might like to:

* Translate menus and navigation labels
* Configure SEO-friendly URLs for multilingual pages
* Add additional languages
* Customize fallback behavior for untranslated content
