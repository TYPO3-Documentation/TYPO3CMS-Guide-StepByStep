# TCA

Guides in this section show how to extend TYPO3 records with the Table Configuration Array ([TCA](https://docs.typo3.org/permalink/t3tca:start)) — from adding a single custom field to the `pages` table up to creating your own child-record tables with inline editing.

Start with [Add a Text Field to a Page Record](AddATextFieldToAPageRecord.md): it establishes the pattern (SQL column, TCA registration, field placement) that every other guide in this section builds on. Then pick the field type you need — checkbox, textarea, date, number, dropdown, file reference — or continue to form layout (tabs, palettes), field behavior (required, conditional display, overrides, translated labels), and relations (database relations, categories, inline child records).
