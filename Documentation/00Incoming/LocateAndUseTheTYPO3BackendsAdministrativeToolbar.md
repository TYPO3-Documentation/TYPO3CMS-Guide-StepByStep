# Locate and use the TYPO3 backend's administrative toolbar

<!-- #TYPO3v14 #Beginner #Backend #Editing @dhubert974 -->

The TYPO3 backend includes an administrative toolbar that provides quick access to essential system actions.

Using the administrative toolbar helps you perform common tasks faster, such as clearing the cache, accessing system information, or managing your user settings without navigating through multiple modules.

## Learning objective

In this step-by-step guide you will learn how to locate the administrative toolbar in the TYPO3 backend and use its main features.

## Prerequisites

### Tools and technology

* Access to a TYPO3 backend (version 14)
* A user account with backend access

### Knowledge and skills

* Basic understanding of the TYPO3 backend interface

## Locate the administrative toolbar

The administrative toolbar is always visible at the top of the TYPO3 backend interface.

1. Log in to the TYPO3 backend.
2. Look at the top of the screen.
3. Identify the horizontal bar containing several icons and menus.
   You should see elements such as:
   * Bookmarks
   * Clear cache
   * System information
   * Search
   * Your user profile

![The TYPO3 backend administrative toolbar at the top of the screen, showing the site name on the left and the toolbar icons on the right](Images/LocateAndUseTheTYPO3BackendsAdministrativeToolbar/Administrative-toolbar.png)

## Use the administrative toolbar

The administrative toolbar provides quick access to frequently used administrative actions.

![Close-up of the administrative toolbar icons, numbered from 1 to 5: Bookmarks, Clear cache, System information, Search, and the user profile](Images/LocateAndUseTheTYPO3BackendsAdministrativeToolbar/Zoom-administrative-toolbar.png)

1. Open **Bookmarks** to quickly access saved backend pages.
2. Click the **Clear cache** icon to flush the system cache.
   For detailed instructions, see [Clearing the Frontend Cache in the TYPO3 Backend](https://docs.typo3.org/m/typo3/guide-step-by-step/main/en-us/10GettingStarted/20BasicConfiguration/10BackendBasics/ClearingFrontendCacheInTypo3Backend.html).
3. Click **System information** to view system status details.
4. Use the **Search** field to find pages, content, or records.
5. Open your **user profile** to access personal settings or log out.
